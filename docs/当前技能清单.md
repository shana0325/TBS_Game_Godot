# 当前技能清单

本清单记录游戏内实际显示的技能效果文本，已从运行中的 `GameDatabase.skills` 和 `MechanicDescription.get_parsed_text()` 核对。共 61 个已注册技能：51 个通用技能、10 个角色或 Boss 专属技能。

角色技能列表、学习/遗忘列表、技能详情正文和技能图鉴条目均使用同一描述组件，因此效果文本一致。详情中的触发时机、伤害类型、技能标签及角色专属成长数值另行显示，不属于下表效果正文。

原编号保留以便讨论；已删除的 J01、J13 不再列入。J12、J16 尚待讨论。S06 已注册，但当前 Hero 使用的固有技能为 S05。
