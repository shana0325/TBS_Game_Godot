# 爬塔敌方数值设计文档

版本：V1.0

## 一、设计目标

本项目采用：
- Roguelike爬塔
- 自动战斗
- 小队构筑
- 角色职业体系
- 通用技能体系
- 遗物体系

敌方单位与玩家共享同一套角色模板，仅通过属性倍率成长与通用技能数量成长实现难度提升。

## 二、设计原则

### 玩家与敌人共用模板

战士：1400 HP / 100 ATK / 25 DEF
坦克：2000 HP / 80 ATK / 50 DEF
射手：1000 HP / 130 ATK / 10 DEF
刺客：800 HP / 160 ATK / 5 DEF

敌方单位直接从角色池随机抽取。

### 难度来源

EnemyPower = 属性成长 + 技能成长

## 三、敌方生成规则

随机角色
→ 读取基础属性
→ 应用层数倍率
→ 加载固有技能
→ 随机获得通用技能
→ 生成敌方单位

## 四、属性成长设计

成长公式：

Multiplier = Growth^(Floor - 1)

Growth = 1.04

### 属性倍率示例

| 层数 | 倍率 |
|------|------|
| 1 | 1.00 |
| 5 | 1.17 |
| 10 | 1.42 |
| 15 | 1.73 |
| 20 | 2.11 |
| 25 | 2.57 |
| 30 | 3.12 |
| 35 | 3.80 |
| 40 | 4.62 |
| 50 | 6.84 |

倍率作用于：

HP = BaseHP × Multiplier

ATK = BaseATK × Multiplier

DEF = BaseDEF × Multiplier

采用LOL护甲公式：

减伤率 = Armor / (100 + Armor)

因此承伤成长速度会略高于输出成长速度，符合“前期怕输出、后期怕打不动”的设计目标。

## 五、技能成长设计

| 层数区间 | 通用技能数量 |
|----------|----------|
| 1~10 | 0 |
| 11~20 | 1 |
| 21~30 | 2 |
| 31+ | 3 |

公式：

SkillCount = min(floor((Floor - 1)/10), 3)

## 六、技能抽取规则

刺客优先：
- 暴击
- 收割
- 斩杀
- 连击

坦克优先：
- 护盾
- 嘲讽
- 反伤
- 减伤

射手优先：
- 远程输出
- 暴击
- 穿透

战士：
- 均衡权重

## 八、调参原则

仅调整：

Growth

默认：

Growth = 1.04

简单：

Growth = 1.03

困难：

Growth = 1.05

禁止维护每层独立数值表。

## 九、V1最终方案

敌人来源：
- 角色池随机抽取

属性成长：
Multiplier = 1.04^(Floor - 1)

作用范围：
- HP
- ATK
- DEF

技能成长：
- 1~10层：0技能
- 11~20层：1技能
- 21~30层：2技能
- 31层以上：3技能

目标：
前期依赖角色基础强度；
中期形成构筑；
后期形成完整构筑并叠加高倍率成长。
