## 当前遗物／通用技能边界

后续设计遗物时，至少满足以下一项：①作用于整个队伍；②改变奖励、装备、技能、商店或爬塔等外围规则；③跨战斗成长或记录整个 Run 的数据；④改变基础战斗规则，而非只增加一个单位的攻击被动；⑤产生队伍组合效应，而非单个单位独立触发。只给每名队员复制同一个独立被动，不单凭“全队”措辞算作队伍组合效应。

不满足任一项的单体攻击、生存、位移等效果归入可学习、可装卸的通用技能库，并按技能位重新平衡。装备技能与通用技能定位重合，当前不设计装备技能；装备仍可提供属性。下文“主题／通用”只区分已符合上述标准的遗物面向哪种构筑，不决定一个效果是否属于遗物。逐项归类见 `docs/LoL符文_遗物一一对应表.md`。

## 0. 理念修正（相对 v1）

v1 说"遗物 = 机制种子，不绑流派"，方向对但不完整。**正确口径**：

- 遗物允许有一定比例的**主题 / 流派向**（鼓励专精某条路线），这一点 v1 矫枉过正了。
- 但**不绑定流派**的遗物必须保留 **30%~50%** 份额，保证混搭与尝试其它路线始终有得玩。
- 断层面的分类改为"**流派向 / 半通用 / 通用**"。一件遗物归属由"触发条件是否绑定某类特定构筑"判定。
- 红线不变：`turn_interval` / 行动速度 ∈ 不升级区，任何遗物不得把它做成成长项。

---

## 1. 三条原则（v2）

1. **分两类留比例**：主题遗物给"专精回报"；通用遗物给"任意队伍都吃"；通用占比锁在 30%~50%。
2. **机制语言源自行为**：无论主题还是通用，触发条件都写在"行为/事件"层（普攻、技能、受击、击杀、护盾、低血、跨层），才能跟真实战斗系统对上，而不是空泛的"流派标签 +25%"。
3. **数值纪律**：同一通道（伤害、减伤、回血、冷却、层成长）设收敛带宽；增长一律加法再封顶；不碰 `turn_interval`。

### 怎么区分"主题"与"通用"
- 视为**通用**：任意队伍都能稳定触发（残血、跨层、护盾存在、经济/规则类增益的存在）。
- 视为**主题**：只有特定构筑路径才能稳定触发（专精连击、专精技能释放频率、只p boost住普攻/只p boost住技能）。

## 2. 五大系方向 × 遗物（核心新增 10 件，0~2/系）

> 参照图源五大系定位与 docx「优先值得借鉴的机制原型」。每件标注归属与借鉴原型。

### 2.1 精密 —— 持续输出 / 普攻 / 叠层 / 续航 / 残血作战
**借鉴原型**：强攻（3 连击→爆发）、坚毅不倒（残血加伤）。

#### 三连追魂刃 triple_strike_blade（主题 · 连击系）R2
- **描述**：对同一目标连续造成 3 次普攻或伤害技能命中后，下一次命中伤害 +50%。
- **数据示意（需扩展）**：
  `triggers:[{ "event":"on_deal_damage", "same_target_counter":3, "hits_after":1, "effects":[{"type":"damage_power_mult","mult":1.5}] }]`
- **设计意图**：奖励"盯住一个打"的连续输出；有连击/追击技能或攻速型构建更易叠，普攻流/技能流都能吃。
- **切合度**：战斗是"每单位独立行动 + 追击连击"，对同一目标连续命中的场景天然存在。

#### 背水之志 last_stand_resolve（通用 · 残血）R2
- **描述**：我方单位生命低于 50% 时，造成的伤害 +15%。
- **数据示意（条件型，可复用技能 `conditional_hp_percent` 思路，需扩展为全局遗物）**：
  `triggers:[{ "event":"constant", "target":"ally", "cond":{"hp_percent":{"lt":0.5}}, "effects":[{"type":"damage_power_mult","mult":0.15}] }]`
- **设计意图**：越残越打，任何单位任何构筑都能触发 → 通用件。
- **切合度**：与"狂暴机制（60s 后全伤害 +50%）"气质一致，但方向相反（按血量），丰富残血博弈。

### 2.2 主宰 —— 爆发 / 刺杀 / 击杀收益 / 视野 / 滚雪球
**借鉴原型**：先攻（先手加伤 + 转化收益）、黑暗收割（击杀→永久层）。

#### 先机之刃 first_strike_razor（主题 · 首击爆发）R2
- **描述**：对生命值高于 80% 的目标，造成的伤害 +30%。
- **数据示意（条件型）**：
  `triggers:[{ "event":"constant", "cond":{"target_hp_percent":{"gt":0.8}}, "effects":[{"type":"damage_power_mult","mult":0.30}] }]`
- **设计意图**：首刀/点名高血量侧重的收割位（"先手博弈"）；爆发刺杀流吃香，但远程/前排也可借残血补刀时机用。
- **切合度**：与"斩杀（目标<30% 加伤）"互补——一个打满血端、一个打残血端。

#### 猎首印记 headhunter_mark（主题 · 击杀滚雪球）R3
- **描述**：我方单位击杀敌人时，全队造成伤害永久 +0.8%（本局，上限 +8%，锁死于本局不清空）。
- **数据示意（需扩展"在 run 会话永久累加附加伤害"）**：
  `triggers:[{ "event":"on_kill", "stack":{"stat":"global_damage_mult","per_kill":0.008,"max":0.08,"persist":"run"} }]`
- **设计意图**：一条"击杀越多越强"的版本引擎（黑暗收割感），局内永久滚雪球。
- **区分**：与现有「以战养战」（击杀涨生命上限）方向相反，做成"涨输出"补全滚雪球纬度。
- **视野**：本作无视野/守卫系统，不硬做，故该方向只出 1 件。

### 2.3 巫术 —— 技能强化 / 法术消耗 / 资源 / 机动 / 后期成长
**借鉴原型**：奥术彗星（技能弹射）、风暴聚集（递增成长）。

#### 奥术回音 arcane_echo（主题 · 技能强化）R3
- **描述**：施放主动技能时，追加对目标相邻 1 格内敌人的一次 60% 攻击力范围伤害。
- **数据示意（需扩展"主动技能命中后 AOE 溅射"）**：
  `triggers:[{ "event":"on_cast_active_skill", "effects":[{"type":"damage","power":0.6,"area_shape":"adjacent","radius":1}] }]`
- **设计意图**：技能系构筑的 AOE 种，契合格子战棋（相邻格）。
- **切合度**：本作技能有目标与射程，追加相邻格 AOE 与棋盘语义一致。

#### 元素沉淀 elemental_accretion（通用 · 跨层成长）R2
- **描述**：每进入一层新楼层，全队技能与普通伤害永久 +1%（本局，上限 +10%）。
- **数据示意（需扩展"跨层事件"）**：
  `triggers:[{ "event":"on_floor_advance", "stack":{"stat":"damage_mult","per_floor":0.01,"max":0.10,"persist":"run"} }]`
- **设计意图**：爬得越深越强（后期成长），贴合爬塔主循环；不分流派，任何单位每层都吃 → 通用件。
- **即把"后期成长"做成"层数成长"**，呼应风暴聚集的递增式收益，又不碰行动速度红线。

### 2.4 坚决 —— 坦度 / 生存 / 回复 / 护盾 / 控制 / 抗压
**借鉴原型**：不灭之握（承伤换短期收益 + 永久成长）、护盾猛击（护盾→加伤）。

#### 不朽之握战印 grasping_seal（半通用 · 承伤成长）R2
- **描述**：每 4 秒强化我方任一单位的下一击：额外造成自身最大生命 3% 的伤害，并回复自身 1% 最大生命；本次击杀使最大生命永久 +5（本局）。
- **数据示意（有"周期强化 + 永久成长"两种，需扩展）**：
  `triggers:[{ "event":"on_battle_tick","interval":4.0,"grant":"empowered_next_attack"}, { "event":"on_kill_by_empowered","stat":"hp_max_permanent","amount":5,"persist":"run"} ]`
- **设计意图**：把"最大生命"变成资源——坦克越多血越强（承伤换收益），同时开局就有短收益。
- **归属**：偏坦克/肉盾构筑，但任意队伍只要带血厚前排就有收益 → 半通用。

#### 庇佑盾章 bulwark_tocen（通用 · 护盾反馈）R2
- **描述**：我方单位获得任意来源护盾时，其下一次造成的伤害附带该次护盾值 15% 的额外伤害。
- **数据示意（需扩展"获得护盾后叠加下次伤害"）**：
  `triggers:[{ "event":"on_gain_shield", "effects":[{"type":"empower_next_attack","by_shield_percent":0.15}] }]`
- **设计意图**：把护盾从"纯防御"变成"攻守转换"；任何能出护盾的构筑（铁壁/护盾系技能/守卫类遗物）都吃 → 通用件。
- **控制后收益**：本作控制类技能极少，暂不做"受控反击"，避免悬空件（计数说明：该子项 0 件）。

### 2.5 启迪 —— 改变规则 / 经济 / 装备 / 召唤师技能 / 消耗品 / 功能性
**借鉴原型**：多面手（奖励构筑多样性）、先攻/现金回馈（经济 + 规则改换）。

#### 集思广益徽记 eclecticism_badge（通用 · 构筑多样性 ★）R3
- **描述**：本局每获得一种新的"增益来源大类"（技能书 / 装备 / 遗物 / 祝福 各算一种），全体造成伤害 +3%，最多 +12%。
- **数据示意（状态监听"本局累计获得来源种类"）**：
  `triggers:[{ "event":"on_acquire_source", "source_kinds":["skill_book","equipment","relic","blessing"], "per_kind":0.03,"max":0.12 }]`
- **设计意图**：**奖励混搭，而不只是专精**——吃（技能书+装备+遗物+祝福）混搭越充分伤害越高。这是本稿贯彻"留非绑定比例"理念的核心件。通用无绑定。
- **切合度**：爬塔本来就不断掉落这四类，天然能量化"多样性"。

#### 赶集行商券 market_prudent_passes（通用 · 经济 / 规则）R1
- **描述**：通关结算三选一奖励时，额外多生成 1 个选项（三选一 → 四选一）。
- **数据示意（领取环节读取）**：
  `effects:[{ "type":"reward_option_bonus","amount":1 }]`
- **设计意图**：把"改变规则/经济"落成"多一手选择权"，每层一次，稳定、通用、零绑定。
- **备注**：需在 `reward_screen` 读取 `reward_option_bonus` 累加选项数；若未来做商店，可再配金币贩遗物。

## 4. 总池与比例核算（确保非绑定 ≥ 30%）

把「现有 5 + v1 通用 8 + 本稿 10」合为大池，按归属归类（半通用按 0.5 计）：

| 分池 | 数量 | 归属 |
|---|---|---|
| 现有 5 件 | 5 | 通用偏数值（含遗留的`急速披风`，需按红线处理） |
| v1 机制种子 | 8 | 全通用 |
| 本稿主题 / 半通用 | 5.t2（三连追魂·主题；先机·主题；猎首·主题；奥术·主题；不朽·半） | 主题 |
| 本稿半通用 | 1（不朽战印，计 0.5） | 半通用 |
| 本稿通用 | 4（背水、元素沉淀、庇佑盾章、集思广益、赶集券→实为 5 件通用） | 通用 |

> 简化核算：**全部通用 + 半通用** ≈ 现有5（通用为主） + v1 8（通用） + 本稿通用5 + 半通用0.5 ≈ **约 70%**；主题/纯流派 ≈ 3.7 件 ≈ 30%。
> → 通用占比落在 **上线在 50%~70% 区间**，满足"通用请留 30%~50% + 流派也可有"的诉求，比例健康（略偏高通用，符合"以体验多样性优先"的取向）。
> 若想更偏向"主题流宇宙更立得起来"，可从通用池中降 1~2 件作主题（如元素沉淀 → 技能流专属）。

## 5. 数值带宽与红线（v2 汇总，含新件）

| 通道 | 允许带宽 | 涉及 |
|---|---|---|
| 伤害加成（常驻/层/跨层） | 单件 ≤ +20%，多件求和后封顶 | 三连(+50%单次) dpi、背水15%、先机30%(限定目标)、猎首8%、集思12%、元素10% |
| 护盾转加伤 | ≤ 护盾值 20% | 庇佑盾章 15% |
| 击杀永久成长 | 每击 ≤ +1%，上限 ≤ +10% | 猎首 0.8%/上限8%；与以战养战(hp)分离通道 |
| 冷却/追加AOE威力 | 追加 ≤ 60% 威力 | 奥术回音 |
| 行动速度 / turn_interval | **0** | 红线 |
| 节奏火花(开局行动预充) | 一次性，非成长 | v1 |
| 遗物永久统计（run） | 同一"消耗到 run" 渠道内可加可封顶 | 猎首/元素/不朽 |

- 多件同类通道 → **求和后再封顶**，禁止乘法叠套。
- `急速披风`（+10% 行动速度）仍是唯一踩线项，建议同 v1 处理（改温和或改档）。

## 6. 实现对接清单 — 本稿新增所需事件/效果

| 能力 | 服务遗物 | 现状 |
|---|---|---|
| 条件伤害倍率 `damage_power_mult`（按目标血量/我方血量） | 三连、背水、先机 | 需扩展（可复用 `Execute` 的 `target_hp_percent` 语法） |
| run 会话永久累加（全局伤害/最大生命） | 猎首、元素、不朽 | 需扩展 `stat ...persist:"run"` |
| 主动技能命中后 AOE 追加 | 奥术 | 需扩展 `on_cast_active_skill` |
| 跨层事件 `on_floor_advance` | 元素 | 需扩展（爬塔流程触发） |
| 获得护盾事件 + 下次伤害强化 | 庇佑 | 需扩展 `on_gain_shield` |
| 周期授模态（每4秒强化下一击） | 不朽 | 需扩展 `on_battle_tick` |
| 统计"获得来源种类"反馈 | 集思广益 | 需扩展 `on_acquire_source` |

> **实现优先级说明**：`叠层 stat`（支撑 v1 的动量/坚盾/愈合 + 本稿猎首/元素）+ `damage_power_mult`（支撑三连/背水/先机）是两个最高杠杆，建议先落这两个框架。

## 7. 遗物档案字段（对齐 docx §8 建议，作为录入规范）

新增遗物统一至少含：`id` / `name` / `desc`（玩家可见一句话）/ `rarity`（1普通·2稀有·3传说）/ `effects` 或 `triggers` / `tags`（构筑/触发标签：普攻、技能、坦度、护盾、残血、击杀、跨层、经济、多样）。

> 录入 `data/relic/relics.json` 时，稀有度沿用现有 `rarity` 数字域并补齐 `tags` 便于未来"按流派拉池 / 按通用拉池"。
