# UI 图片素材介绍

以下是当前 `assets/reference/ui_material` 文件夹中保留的候选 UI 图片。它们目前没有被游戏场景或主题引用，仅用于后续视觉迭代参考；按钮、面板和卡片素材建议使用 `StyleBoxTexture` 九宫格方式拉伸，避免边角装饰变形。

| 图片名称 | 图片介绍，适用于做什么 |
| --- | --- |
| `button_primary.png` | 紫色幻想风格的主要按钮，带金色装饰边框和上下中央装饰。适用于“开始游戏”“开始战斗”“保存并开始游戏”“选择奖励”等推进流程、需要强调的主要操作。 |
| `button_secondary.png` | 冷蓝色调的次要按钮，带金色/银蓝色装饰边框。适用于“返回”“关闭”“撤回”“查看记录”等辅助操作，与主要按钮形成层级区分。 |
| `card_character_frame.png` | 竖向角色卡片边框，适合包裹角色立绘、角色名称、职业、稀有度和属性摘要。也可以用于遗物卡、祝福卡或其他纵向奖励选择卡。 |
| `panel_common.png` | 暗紫色通用信息面板，带完整装饰边框。适用于部署界面的编成面板、战斗日志、角色属性区、奖励说明区和普通信息容器。 |
| `panel_popup.png` | 层级更高、装饰更明显的弹窗面板。适用于战斗设置、角色详情、技能说明、遗物详情以及需要覆盖主界面的确认窗口。 |

## 使用建议

- `button_primary.png` 和 `button_secondary.png` 是横向素材，适合设置左右纹样的九宫格边距后横向拉伸。
- `card_character_frame.png` 是纵向卡片素材，适合固定角落后纵向或双向拉伸。
- `panel_common.png` 和 `panel_popup.png` 适合作为 `PanelContainer` 的背景样式；中间区域可以拉伸，四角边框应保持原比例。
- 图片不包含按钮文字或角色文字，文字应继续由 Godot 的 `Button`、`Label` 绘制，便于修改和本地化。
- `processed/` 中的透明处理副本是历史中间文件；正式使用时应先确认视觉效果，再将确定使用的素材复制或移动到对应的运行时资源目录，并补充场景/主题引用。
